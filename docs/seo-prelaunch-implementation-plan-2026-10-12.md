## Final verification and handoff

- Automated checks are **PLANNED, NOT RUN**. Respect the workspace restriction: do not run tests, lint, typecheck, or builds without the direct `npm run build` request that opens that gate. Once authorized, run `npm run test -- src/test/seo-resource-links.test.tsx`, relevant existing sitemap/locale metadata suites, and new targeted cases; then `npm run build`. Capture failures and rerun only affected checks after corrections.
- Use an authorized production-equivalent preview to crawl every current sitemap URL and rendered internal destination. Expect canonical public pages to return 200 with useful content; missing pages must have appropriate missing-page behavior, noindex, and no incoming promoted links. Check robots, alternates, redirects, and private/checkout/preview exclusions separately. Do not remove intentional noindex controls to make a check pass.
- Check English/Spanish interactive navigation, archive search/category filtering, mobile rendering, keyboard access, rendered JSON-LD, and consent-respecting inquiry/booking events. Measure production-equivalent mobile performance; label laboratory results separately from unavailable field data. Confirm the uncapped archive's page weight is acceptable.
- Record blockers and obtain release authorization before deployment or CMS publishing. After authorized launch, verify the production signals again, submit the approved sitemap through verified Search Console access, and review crawl/index errors immediately, visibility weekly, and qualified conversions monthly. Baseline metrics remain MISSING until collected.

## Rollback and deferred work

Before any authorized CMS mutation, export affected documents. Before redirect/indexing changes, record previous rules and affected URLs. Roll back only this work's code hunks or exported content, preserving other contributors' changes; retain the prior release artifact for release-owner rollback. Never use a whole-tree reset as recovery.

Deferred: new SEO dependencies, mass content generation, backlink campaigns, broad redesign, and archive pagination until measured catalog growth/page weight warrants it. Article schema is optional; translations, usable promoted destinations, indexing controls, and verification take priority. Deployment, actual Google indexing, field Core Web Vitals, tax-law accuracy, and performance outcomes remain unverified until the appropriate owner supplies evidence.
